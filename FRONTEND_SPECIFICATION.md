### Summary of Key Resources for Frontend Development
* **Handoff Guide & API Documentation:** `docs/FRONTEND_HANDOFF.md`

* **Mandatory Judge Requirement:** Tour Guide Date Clash Refusal & Substitute Recommendation flow (§2.2).

To start frontend dev server:
```bash
cd frontend
npm install
npm run dev
```
Navigate to `http://localhost:5173`.
